Video Explorer settings

Changes are saved right away and apply to an open popup immediately.

Why does Video Explorer make its own requests?

Even when a video or GIF is already showing on the page, the popup can’t reuse it. Chrome keeps a separate cache for each site, and the extension counts as a different site, so a thumbnail in the popup is downloaded from the server again. The page also often shows only a preview and loads the real file when you press play, while the extension asks for the file itself. File sizes need a request of their own, and a GIF thumbnail downloads the whole GIF.

The server sees all of this as more requests from you, and counts it toward the same limit as the page. That’s why a strict site can start answering “too many requests” and stop showing its own videos. The Auto settings keep requests few and spaced out, and pause when a site pushes back. If a site still has trouble, set Thumbnails and lengths to Off and File sizes to Only what the page revealed. Then the popup makes no extra requests at all.
